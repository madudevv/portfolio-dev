# Portfólio Dev — Maedu

Portfólio pessoal desenvolvido com o objetivo de apresentar minhas habilidades, experiências e projetos na área de desenvolvimento de software.

O projeto utiliza a API pública do GitHub para exibir meus repositórios dinamicamente, sem a necessidade de cadastrar cada projeto manualmente no HTML.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub
- GitHub REST API

## Funcionalidades

- Apresentação pessoal e profissional.
- Exibição das minhas habilidades.
- Consumo de uma API pública.
- Listagem dinâmica dos repositórios do GitHub.
- Manipulação do DOM com JavaScript.
- Layout responsivo.
- Navegação suave entre as seções.
- Interface personalizada com tema escuro e pixel art.
- Animações e efeitos visuais com CSS.

## Aprendizados

Durante o desenvolvimento deste projeto, pude aprofundar meus conhecimentos em:

- Requisições HTTP com Fetch API.
- Programação assíncrona com async e await.
- Manipulação de elementos HTML pelo JavaScript.
- Organização de layouts com Flexbox e CSS Grid.
- Pseudoclasses e pseudoelementos.
- Responsividade com Media Queries.
- Versionamento de código com Git.

## Como executar

1. Clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.

Não é necessário instalar dependências.
